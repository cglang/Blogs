>记录一下这次给我的日常使用电脑安装上 Linux 系统的使用感受。

上次使用 Linux 作为日常电脑还是21年刚毕业那时候，前几个月出差时在酒店里 Windows11 更新给我更新的无法进入引导，修了半天没修好，一气之下装上了 Debian，之前也体验过其他的发行版 Ubuntu / Deepin / Arch / Fedora / Linux Mint，还有一些小众的都忘了名了，基本上大大小小的在实体机虚拟机体验过十来种要多。

之前使用 Linux 最大的问题就是没有微信和QQ，虽然有多种方式能够让这两个在Linux上运行，但总有一些细节让人觉得别扭，但现在不同了，微信和QQ现在都原生支持Linux，这一方面国产化还有信创可以说是功不可没，我觉得因为这两个软件的问题让太多的人放弃Linux，不得不使用Windows，我就是其中一个。

另一个比较恼人的问题是输入法，Linux下主要有两种输入法 IBus 和 Fcitx，之前一直用的桌面环境是 Gnome，这个桌面默认是用的IBus，不太记得遇到什么问题了，好像是有一些应用内能输入中文有一些应用内不能输入中文，这个问题应该是一些环境变量没有配置正确，当时也找不清该怎么配，并且 Linux 下面应用有GTK的有QT的光GTK都分好几个版本，当时确实是有点乱（虽然现在也挺乱的），光这个输入中文的问题就要经常折腾，说实在的输入法没有了解到有什么很大的改变，但这次换上了KDE+Fcitx+Rime，输入法上面还真没遇到什么让人接受不了的地方，甚至是没有什么槽点，跟Windows使用中大差不差的。

还有一个问题非常的大问题，当时用的电脑是使用的是Nvida显卡，Linux上的Nvida显卡驱动真的做的是太懒了，经常出问题，我印象比较深的是更新一下内核驱动显卡驱动版本没更上，界面就打不开了，只能把内核版本回滚使用旧版本的，虽然后面也知道了有一种方法在更新内核之后能够做到自动编译更新显卡驱动，但那都是后面的事情了，当时还做不到随心所欲的这么去折腾。

前几年的时候其实Wayland还没像现在这么可用性这么高，当时主流还是X11，然后还出了个XWayland，当时有一些“技术洁癖”，总觉得Wayland更好，就要用Wayland，那后果就是各种桌面框架问题，整天光去解决这种乱七八糟的事情了，现在Wayland很成熟了，Genome和KDE都默认是Wayland，至少目前用下来没有出现什么大问题，甚至是小问题也极其少见。

游戏也是一个挺大的问题，直到这两年，Steam出了一个技术叫做Proton，他把这款产品做的挺好的，虽然是个兼容层，但是性能是真的棒，并且我还是AMD的显卡，性能跟Windows几乎一模一样，完全感受不出来有性能损耗，甚至是因为显卡驱动的问题部分游戏可能比Windows还要流畅。

到这里日常使用的软件微信 / QQ 有了，办公用的Office用WPS就足够日常使用，开发软件VS Code / IDEA / Rider 前端后端都能行，浏览器本来就挺好Chrome / Edge / Firefox，主流的受好评的浏览器都支持三大平台，这倒没什么好说的。

说到底我喜欢Linux的什么？

命令行 bash 比 Windows 的 CMD / Powershell 要用的顺手

桌面定制化要比 Windows 自由

系统简洁没有额外的内容，不会被绑架强制使用

AI Agent使用体验要比Windows要好

安装软件包管理器一个命令搞定，比点点点省心

远程管理也要顺手的多，我现在还经常用VS Code的SSH连到我的电脑改一些东西

没有强制更新，我想更新了我就更新，我想更新哪个我更新哪个，不会强制

资源占用也低，之前Windows我的笔记本不插电只能用两三个小时，现在能用一整天还有电

文件系统权限做的要比Windows简介，并且我想删哪个文件就删哪个文件，Windows下有一些文件还得需要对应的权限才能

容器原生的好用，Windows的容器虽然很完善，但是就感觉用起来别扭，尤其是那个Docker Desktop，那界面打开就有一股莫名的复杂感从心底产生

社区文化，这一点Windows是没有的，Windows环境中只有吸血鬼，Linux的社区文化绝对是独一份的存在

可控感和自由这一点是Windows没有的

总之我现在已经没有必须要使用Windows的理由了，Linux能够提供的功能完全满足我对电脑的使用情况，甚至部分情况只有Linux才能满足，Linux 桌面这两年终于从"折腾"变成了"不用折腾"，而我也从"想折腾"变成了"想干活"——两边刚好对上，它就成了我的日常机就显得理所当然。
